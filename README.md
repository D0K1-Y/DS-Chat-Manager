# DeepSeek 对话文件夹

给 DeepSeek 网页版的对话历史加一层**文件夹**：建多个文件夹，把对话归进去。原生列表一条都不改，纯本地存储，不联网。

> 📖 完整使用说明见 [使用说明.md](使用说明.md)
>
> 状态：v0.3.1 · **M3 已完成**（文件夹改名 / 置顶 / 排序 / 删除确认 / 备份 / 新对话提示）
> 下一步 M4：深浅色细节打磨、抗改版兜底、开源发布准备

## 安装（开发者模式）

1. 打开 `chrome://extensions`（Edge 用 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本仓库的 `extension` 目录
4. 打开 https://chat.deepseek.com ，侧栏「历史对话」上方会出现一行 **文件夹**

## 怎么用

**建文件夹**：点侧栏「文件夹」→ 面板底部「＋ 新建文件夹」→ 输入名字回车

**归类（两种方式）**

1. **拖拽**：直接按住左侧对话列表里的某条对话，拖到面板里的文件夹上，松手即可
   （面板没开的话，开始拖的瞬间会自动弹出来）
2. **右键**：在对话上点右键 →「移动到文件夹」→ 选文件夹（已归类过的会打 ✓，下面还有「移出文件夹」）

**看文件夹里的内容**：点文件夹 → 进入文件夹视图，点任意一条就正常打开该对话；
鼠标移到条目上出现「移出」，点了就放回未归类。

**删除同步**：在 DeepSeek 历史列表里删掉一条对话，文件夹里对应的记录会自动移除（有 2.5 秒缓冲，
期间对话重新出现会自动取消；整表重渲染不会误删）。

**管理文件夹**：鼠标移到文件夹行，右侧出现 `⋯`，里面是：

- 重命名（行内改，回车保存）
- 置顶 / 取消置顶（置顶的排最前，图标变 ★）
- 上移 / 下移（手动调顺序）
- 删除文件夹（行内二次确认，**里面的对话不会被删，只是回到未归类**）

**备份**：面板底部 `⋯` → 导出备份 / 导入备份。导出是一个 JSON 文件。

> ⚠️ **重要**：在 `chrome://extensions` 里「移除」扩展会连带清空它的存储。
> 想保留数据请用 ⟳ 重载；要重装前先导出备份。

**新对话提示**：页面打开后新建的对话，会在右下角弹一张小卡片问「放进哪个文件夹？」。
历史对话不会提示。开关在面板底部 `⋯` →「新对话时询问」。

**开关**：点扩展图标 = 一键显示 / 隐藏入口（图标出现 `OFF` 表示已隐藏，**数据不会丢**）
- 面板里点空白处或按 `Esc` 关闭

## 目录结构

```
extension/
  manifest.json        MV3 清单
  src/store.js         数据层（chrome.storage / localStorage 兜底）
  src/ui.js            面板 UI（Shadow DOM 隔离）
  src/main.js          入口注入 + SPA 重连 + 诊断
  src/background.js    图标点击开关
  src/host.css         入口行样式（注入在页面里）
  src/panel.css        面板样式（Shadow DOM 内）
  icons/               16 / 32 / 48 / 128 图标
dev/
  mock.html            本地模拟页（模拟 DeepSeek 侧栏）
  test-real.html       用真实侧栏 HTML 做的选择器回归页
  preview.png          渲染截图
```

## 数据与隐私

- 只保存「文件夹名称」和「对话 id → 文件夹」的映射，不存对话内容
- 存在 `chrome.storage.local`，不上传、不联网、不碰账号凭证
- 卸载扩展 = 数据一起清掉（导出功能在 M3）

## 选择器校准（2026-11）

按真实侧栏 DOM 校准过，入口插在对话列表的**第一个子节点**，也就是「置顶 / 今天 / 昨天」这些分组之上：

~~~
a[href*="/chat/s/"]       每一条对话（UUID 就是会话 id）
  div._62cad32            一组条目
  div._3098d02            分组（置顶 / 今天 / 昨天 / 7 天内）
div._77cdc67              列表根        ← 入口插到这里
div._6d215eb.ds-scroll-area  滚动容器
~~~

哈希类名（_77cdc67 这种）DeepSeek 每次发版都可能变，所以代码**不依赖哈希**，
只依赖两点：对话链接的 href 前缀 + 外层是滚动容器。

## 已知限制

- 改名如果导致记录异常，在控制台执行 `DSCM.diag()` 可以看到最近的「迁移 / 删除」事件。
- DeepSeek 大改版后入口可能不出现。出问题时在控制台执行 `DSCM.inspect()`，
  它会告诉你：找到几条对话链接、列表根是什么、入口有没有插进去、是不是第一个子节点。
- 目前只支持 chat.deepseek.com 桌面版。
