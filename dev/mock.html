Vue3 响应式原理分享
Vue3 的响应式原理用 Proxy 实现，那它和 Vue2 的 defineProperty 有什么本质区别？
D
核心区别在于拦截的粒度与能力：defineProperty 只能劫持已存在的属性，新增和删除属性需要额外的 API 辅助； 而 Proxy 是对整个对象的代理，可以拦截 get、set、deleteProperty、has 等 13 种操作， 因此天然支持数组索引与 length 的变化，也就不需要 Vue2 那套重写数组方法的补丁。
